PASS if the plan names two or three outside products or design systems as references for a settings or billing page (for example Stripe, Vercel, Linear, Proton, Grafana Saga), says for each what it contributes (density, hierarchy, states, motion or copy tone), says how the finished page will be compared against them (screenshots at the same viewport and theme, or measured values), and says that principles are taken, not a brand's look, logo or copy.
FAIL if the plan names no outside reference, names references without saying what each contributes, picks references for a different surface type only (for example only a marketing site for this settings page), or proposes copying a brand's look.
