# Terms: analytics and SEO

verified 2026-11-04. Identity and category only. Features, limits and hosting regions change; look them up live. "Analytics" alone is ambiguous: see ambiguous.md.

| term | aliases | what it is | not to confuse with | official URL |
|---|---|---|---|---|
| Google Search Console | GSC, Search Console, Webmaster Tools (old name) | Free Google tool for search impressions, clicks, indexing and sitemaps | Google Analytics | https://search.google.com/search-console/about |
| Bing Webmaster Tools | BWT, Bing Webmaster | Microsoft's counterpart of Search Console | Bing Ads | https://www.bing.com/webmasters/about |
| Plausible | Plausible Analytics | Privacy-focused web analytics, cloud or self-hosted | Plausible as a plain word, GA4 | https://plausible.io/ |
| Matomo | formerly Piwik | Open-source web analytics, cloud or self-hosted; renamed from Piwik in 2018 | Piwik PRO, a separate commercial product | https://matomo.org/ |
| Umami | - | Open-source privacy-focused web analytics | Plausible | https://github.com/umami-software/umami |
| Pirsch | - | Privacy-focused web analytics from Germany; Unverified: its website did not resolve from the build environment, the repository does | Plausible | https://github.com/pirsch-analytics/pirsch |
| etracker | - | German web analytics and optimisation suite | Tracker in the sense of ad tracking | https://www.etracker.com/ |
| GA4 | Google Analytics 4, Google Analytics | Current Google Analytics generation; Universal Analytics (UA) was retired | Search Console, Tag Manager | https://support.google.com/analytics/ |
| Google Tag Manager | GTM | Tag container that loads scripts and pixels | GA4 | https://tagmanager.google.com/ |
| Data Studio | Looker Studio, Google Data Studio | Google's reporting and dashboard tool; called Data Studio, then Looker Studio from 2022, and Data Studio again since 2026 | Looker (separate enterprise BI product) | https://lookerstudio.google.com/ |
| UTM | UTM parameters, utm_source | Query parameters that tag the campaign source of a visit | referrer header | https://support.google.com/analytics/answer/1033863 |
| CrUX | Chrome UX Report | Dataset of real-user performance from Chrome users | Lighthouse (lab data) | https://developer.chrome.com/docs/crux |
| PageSpeed Insights | PSI, PageSpeed | Google tool that shows CrUX field data plus a Lighthouse lab run | Lighthouse alone | https://pagespeed.web.dev/ |
| Core Web Vitals | CWV, LCP, INP, CLS | Google's page experience metrics: loading, interactivity (INP replaced FID) and layout stability | Lighthouse score | https://web.dev/articles/vitals |
| IndexNow | - | Protocol to tell participating search engines about changed URLs | Google indexing API, sitemaps | https://www.indexnow.org/ |
| Sistrix | - | German SEO visibility index and toolbox | Search Console | https://www.sistrix.de/ |
| hreflang | - | HTML or sitemap annotation that links language and region variants of a page | canonical | https://developers.google.com/search/docs/specialty/international/localized-versions |
| canonical | rel=canonical, Canonical URL | Annotation naming the preferred URL among duplicates | redirect, hreflang | https://developers.google.com/search/docs/crawling-indexing/consolidate-duplicate-urls |
