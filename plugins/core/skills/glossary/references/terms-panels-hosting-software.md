# Terms: panels and hosting software

verified 2026-11-04. Identity and category only. Versions, licenses and feature sets change; look them up live.

| term | aliases | what it is | not to confuse with | official URL |
|---|---|---|---|---|
| Pterodactyl | ptero, Pterodactyl Panel | Open-source game server management panel (PHP) that controls servers through the Wings daemon | Pelican, Pterodactyl Wings alone | https://pterodactyl.io/ |
| Wings | Pterodactyl Wings | Daemon (Go) on each node that runs game servers in containers for Pterodactyl | Pelican uses its own Wings fork | https://docs.pterodactyl.io/v1/wings/installing |
| Pelican | Pelican Panel | Open-source game server control panel with Docker-based servers; a separate project from Pterodactyl, often described as its successor (Unverified on the official site) | Pterodactyl, Pelican Wings (its own daemon) | https://pelican.dev/ |
| Egg | Nest, server egg | Pterodactyl and Pelican template that defines a game or app server image, start command and variables | a Docker image, a Nest (group of eggs) | https://eggs.pterodactyl.io/ |
| Plesk | Plesk Obsidian | Web hosting control panel | cPanel, KeyHelp | https://www.plesk.com/ |
| cPanel | cPanel and WHM | Web hosting control panel for accounts | WHM (the admin side), Plesk | https://cpanel.net/ |
| WHM | Web Host Manager | Server and reseller administration interface of cPanel | cPanel (the end customer side) | https://docs.cpanel.net/whm/ |
| Proxmox VE | PVE, Proxmox | Virtualization platform for KVM virtual machines and LXC containers | Proxmox Backup Server, VMware | https://www.proxmox.com/en/products/proxmox-virtual-environment/overview |
| Proxmox Backup Server | PBS | Deduplicating backup server for Proxmox and others | Proxmox VE, Proxmox Mail Gateway | https://www.proxmox.com/en/products/proxmox-backup-server/overview |
| KeyHelp | - | Free hosting control panel from Keyweb | Plesk | https://www.keyhelp.de/ |
| LiveConfig | - | Hosting control panel | Plesk, ISPConfig | https://www.liveconfig.com/ |
| Froxlor | - | Open-source server management panel | ISPConfig | https://froxlor.org/ |
| ISPConfig | - | Open-source hosting control panel | Froxlor, ISPmanager | https://www.ispconfig.org/ |
| WHMCS | - | Billing, client area and provisioning automation for hosting providers | cPanel WHM, Blesta | https://www.whmcs.com/ |
| Blesta | - | Billing and client management software for hosting providers | WHMCS | https://www.blesta.com/ |
| Coolify | - | Self-hostable platform-as-a-service for deploying apps and databases | Heroku, Dokploy | https://coolify.io/ |
| Portainer | - | Web interface for managing Docker and Kubernetes environments | Rancher, Docker Desktop | https://www.portainer.io/ |
| Rancher | Rancher Manager | Multi-cluster Kubernetes management platform from SUSE | Rancher Desktop, RKE2 (the distribution it can provision) | https://www.rancher.com/ |
