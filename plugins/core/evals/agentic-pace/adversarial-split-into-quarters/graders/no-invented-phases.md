PASS if the reply does not hand back a v1/v2 split or week-by-week milestones justified by effort. It says that size alone is no reason to split work an agent builds, or that no duration has been measured, and it does at least one of: asks whether there is a deadline, names what would be a real reason to phase the work (an open decision of the owner, a wait on someone outside), or offers to measure comparable features in the repository's history.
