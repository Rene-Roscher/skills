# Approved examples: format

Copy the `examples/` folder to `docs/voice/examples/`. One file per surface and language, named
`[surface].[lang].md`, for example `ui-error.de.md`, `empty-state.en.md`, `mail-receipt.de.md`.

Each file holds 3 to 5 texts that shipped and that the copy owner approved. Only real, shipped texts go here.
A text written to fill this folder is not an approved example; leave the file out instead, and the drafting
agent will say that no examples exist.

Per text:

    ## [where it ships: screen, mail name or page]
    Approved: [YYYY-MM-DD] by [role] · Shipped: [release or date]

    [the text exactly as shipped, including button labels]

Remove customer names, personal data and anything from private mail before you paste a text here.
