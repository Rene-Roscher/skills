# business

Product discovery, pricing and unit economics for B2B SaaS, and copy that reads as written by a person.

## Skills

| Skill | Use it when |
|---|---|
| `product-strategy` | shaping a product or feature: the problem, the buyer, the market, positioning and the metric that shows it works |
| `pricing-and-unit-economics` | setting or changing prices, plans and limits, or checking that a customer costs less than it pays |
| `human-copy` | writing or reviewing website, product, changelog, mail or docs text in English or German |

## Install

```text
/plugin marketplace add Rene-Roscher/skills
/plugin install business@rene-roscher-skills
```

The plugin depends on `core` from this marketplace, which is installed with it.

## How rules are tagged

Rules marked `[invariant]` hold in every project. Rules marked `[default]` hold unless the project records a
different choice in an ADR that names the trade-off.
